# Semana 2 (producción 8–12 jun) — Guía para no confundirse con la numeración
> Actualizado: 15 julio 2026

En este proyecto conviven **dos numeraciones distintas**:

1. **Número de Pub (carpetas `pub-NN_...`):** el número histórico y global de cada publicación, asignado cuando se produjo. **Nunca cambia** (regla del proyecto).
2. **Prefijo de día de republicación (imágenes `NN-...`):** el orden en que se publica en el tenant de GCO según `Planeacion/calendario-republicacion_teams-de-gco.md`. **El primer número de cada imagen siempre es el día de republicación.**
