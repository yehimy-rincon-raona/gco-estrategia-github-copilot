**Autentica GitHub Copilot desde la terminal**

> ¿Trabajas desde consola? GitHub Copilot también responde ahí. En el **Video 03 configuración del entorno** ves la autenticación completa desde la terminal.

⚡ **3 claves del proceso:**

- **Abre la terminal dentro del proyecto** con el que vas a trabajar — no en la carpeta general.
- **Escribe `/` para ver los comandos disponibles,** selecciona `login` y elige github.com cuando te pregunte cómo autenticarte.
- **Autoriza con el código de dispositivo:** abre el enlace con Control + clic, pega el código y autoriza el acceso.

Cuando la terminal confirme que la sesión está iniciada, GitHub Copilot ya está listo para responder desde consola. Entorno configurado.

👉 Mira el vídeo y complétalo con tu proyecto abierto.
